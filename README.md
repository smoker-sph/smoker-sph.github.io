# Smoker

This website provides a service to automatively get the laser-cutting / plasma-cutting files required for creating a classic smoker. It will feature certain free variables such as length, height and diameter and cooking zone depth which can be used to adapt the smoker to your certain wishes. It will be possible to select a chimney to smoke some saussages as well.

If I'll get to it, the smoker will feature a PID feedback controlled fan system with temperature sensors, which can be used to heat to a certain operating temperature.
